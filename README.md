# Chumash-ha-Arizal

Weekly parasha study through the Arizal, worked sentence by sentence from a
printed edition. One directory per parasha:

```
<Parasha>/
  Notes/<Parasha>.md    sentence-by-sentence study notes
  Slides/NN.md          slide decks; ./gen.sh builds NN.pptx from them
```

## Scans

The scanned pages of the printed edition are **not** in this repository. They
are archived on Google Drive, and each parasha's notes link to its PDF in the
`## Progress` section.
